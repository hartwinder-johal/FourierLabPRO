# Contributing to Fourier Lab PRO

Thanks for your interest in improving Fourier Lab PRO. Bug reports, feature ideas, documentation updates, testing and code contributions are welcome.

## Before you start

- Check the existing [issues](https://github.com/hartwinder-johal/FourierLabPRO--Hartwinder/issues) and [pull requests](https://github.com/hartwinder-johal/FourierLabPRO--Hartwinder/pulls) to avoid duplicate work.
- For a substantial change, open an issue first so the approach can be discussed.
- Keep changes focused and explain why they are useful.
- Do not include passwords, API keys, private data or other secrets in issues or commits.

## Reporting a bug

Use the **Bug report** issue template. Include:
- Browser and operating system.
- Steps to reproduce the problem.
- What you expected and what happened.
- Screenshots, console errors or a small example file, if useful.

## Suggesting a feature

Use the **Feature request** template. Describe the problem the feature would solve, the expected behaviour and any relevant examples.

## Code contributions

1. Fork this repository.
2. Create a branch for your change.
3. Make and test your changes in a current browser.
4. Keep the interface consistent with the existing application.
5. Update documentation when behaviour or setup changes.
6. Open a pull request against the `main` branch and complete the pull-request template.

Please do not claim tests were run unless they were. Include the browser and checks you actually performed. For visual or interactive changes, attach screenshots or a short recording when possible.

## Review process

The maintainer will review proposed changes, may ask questions or request revisions, and decides whether to merge them. A pull request is not part of the official project until it has been reviewed and merged.
