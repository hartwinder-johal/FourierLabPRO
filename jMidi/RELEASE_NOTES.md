# jMidi 1.0.0 release notes

- Added a dedicated MIDI In / Out monitor.
- Added live input/output port status and traffic counters.
- Added last-message timestamps and message summaries.
- Added separate receive and successfully-sent event logs.
- Added queue-depth and dropped-event diagnostics.
- Added thread-safe diagnostics snapshots.
- Added Windows CI and executable packaging workflow to the source project.

Validation: 67 passed, 1 skipped locally. PySide6 GUI runtime, Windows executable and physical MIDI hardware acceptance are not claimed as completed in the local environment.
